# 앳홈카케어 비회원·회원 동시 이용 구조

## 경로 1 — 비회원 일일세차
- 홈 비회원 세차 예약 → 로그인 없이 예약 폼 접속 → 차량·연락처·방문 정보 입력 → 기존 Supabase 예약 접수
- 일일 외부세차 기본 선택, 외부+내부·고급 세차 선택 가능
- 비회원 예약만으로 개인 이력이나 다른 고객 예약 조회 권한이 생기지 않음

## 경로 2 — VIP 신규 신청
- VIP 혜택 또는 예약 화면 VIP 신규 신청 선택 → 월 2회·4회 상담 신청
- 접수만으로 실제 계약 생성·횟수 차감 없음. 운영자가 상담 후 VIP 계약을 별도 등록

## 경로 3 — 기존 VIP 회원
- 홈의 VIP 회원 로그인 또는 내 관리 → 휴대폰 OTP 인증 후 본인 기록과 실제 계약 조회
- 유효한 계약과 잔여 횟수가 있는 경우만 기존 VIP 방문 요청 버튼 제공
- 방문 요청은 기타 상담 예약으로 접수. 관리자 확인/완료 연결 후에만 이용권 차감
- 본인인증을 마쳤지만 계약이 없는 일반 고객도 본인의 기존 일일세차 이력을 확인할 수 있음

## 운영·보안
- 익명 예약 INSERT만 허용; 고객 예약 목록 공개 조회 불가
- 개인 기록/잔여 횟수는 휴대폰 인증 후 서버 측 본인 확인으로 조회
- SMS 발송업체 설정 및 실제 로그인·예약 테스트가 별도로 필요

## 운영 점검 체크리스트
- [ ] 비회원 CTA가 로그인 없이 일일 외부세차 예약으로 이동
- [ ] 비회원 예약이 정상 접수되고 VIP 계약은 생기지 않음
- [ ] 신규 VIP 월4회 신청은 별도 신규상담 표시
- [ ] VIP 기존 방문 요청이 신규 계약·자동 차감으로 잘못 처리되지 않음
- [ ] 유효 VIP 계약의 잔여횟수가 0이면 기존VIP 방문 버튼을 숨김
- [ ] 회원 OTP 인증 성공/실패, 타 고객 정보 비노출 확인
- [ ] 모바일과 데스크톱에서 예약 2단계, 홈 버튼과 메뉴가 동작
