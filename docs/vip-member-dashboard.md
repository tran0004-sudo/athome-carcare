# 앳홈카케어 VIP 마이페이지 운영 안내

## 사용자에게 보여주는 정보
- 본인인증 완료 후 확정된 다음 방문 일시 및 이후 예약 최대 6건
- 접수 상태의 대기 예약 최대 5건
- '완료'로 기록된 최근 세차 이력 최대 20건
- 이번 달 완료 횟수 및 누적 완료 횟수
- 가장 최근의 월 2회 / 월 4회 신청 내역

**주의:** 현재 데이터 모델에는 정기회원 계약/만료일/남은 횟수를 관리하는 별도 테이블이 없습니다. 따라서 화면은 최근 **신청 기록**으로 표시하며 유효한 멤버십 계약 상태나 남은 회차로 오인하지 않도록 문구를 조정했습니다.

## 필수 운영 설정
1. Supabase 프로젝트 `xejdhnwqqaamujkebvne` → **Authentication → Providers → Phone**에서 휴대폰(SMS) 로그인과 발송 업체를 설정합니다.
2. SMS 발송 업체의 비용, 이용 지역(대한민국), 발송 규칙 및 Auth rate limit을 확인합니다.
3. 실제 본인 휴대폰에서 OTP 문자가 도착하는지, 번호 인증 및 세션 종료가 동작하는지 테스트합니다.
4. 관리자가 예약을 '확정'하고 `scheduled_at`을 저장해야 '다음 세차 예정일'이 보입니다. '완료' 처리된 방문은 `done_at`을 기준으로 이력에 나타납니다.
5. 새 예약이 본인 계정과 연결되려면 고객이 예약할 때 입력한 휴대폰 번호와 Supabase 인증된 휴대폰 번호가 같아야 합니다. 하이픈이나 +82 표기 차이는 서버에서 정규화합니다.

## 개인정보 보호
- 클라이언트가 임의 전화번호로 예약 이력을 조회하는 API는 없습니다.
- 서버 SQL RPC `get_my_carcare_dashboard`는 `auth.uid()`로 식별한 `auth.users.phone`과 `phone_confirmed_at`을 확인합니다.
- RPC는 `anon`과 `PUBLIC`의 EXECUTE 권한을 제거했습니다. 인증된 이용자만 실행할 수 있습니다.
- 화면에 연락처, 차량번호, 아파트 상세주소, 관리자 메모, 금액은 제공하지 않습니다.
- 세션 토큰은 브라우저 탭의 `sessionStorage`에만 저장되고 로그아웃 시 제거됩니다. 공용 기기는 로그아웃 안내를 표시합니다.
- 페이지는 서버에서 인증된 기록을 조회합니다. 로그인 전에는 개인 일정이 렌더링되지 않습니다.

## 수동 테스트 체크리스트
- [ ] 인증 문자 미설정 시 오류 안내만 표시되고 고객 기록이 노출되지 않음
- [ ] 잘못된 OTP 거부, 올바른 OTP 성공
- [ ] 새 고객: 빈 일정/이력 상태 정확히 표시
- [ ] 예약 '접수' 상태: 확정 예정일로 잘못 표시하지 않음
- [ ] '확정' + 미래 `scheduled_at`: 다음 예정일에 표시
- [ ] '완료' + `done_at`: 이력, 이번 달 완료 횟수에 표시
- [ ] 다른 번호로 인증 시 해당 번호의 데이터만 표시
- [ ] 로그아웃 시 모든 회원 정보를 화면에서 숨김
- [ ] 모바일 화면에서 하단 '내 관리'와 일정·이력 카드 정상 표시
