# 데이터베이스 SQL (Supabase)

파일 이름 맨 앞 두 자리가 **실행 순서**, 그다음 8자리가 만든 날짜입니다.
새로 SQL을 만들면 마지막 번호 다음 번호를 붙여 이 폴더에 넣고, 아래 표에 한 줄 추가합니다.

## 실행 방법

Supabase → **SQL Editor**에 파일 내용을 붙여넣고 **한 번에** 실행합니다.
이미 운영 중인 DB에는 지금까지의 파일이 적용되어 있으므로, **새로 추가된 파일만** 실행하면 됩니다.
DB를 처음부터 새로 만들 때만 0단계부터 순서대로 전부 실행합니다.
