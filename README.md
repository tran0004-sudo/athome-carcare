# 집앞세차-앳홈 카케어 PWA

**중산지구·시지 집중관리 · 대구·경산 전지역**을 대상으로 하는 아파트 방문세차용 모바일 PWA입니다. GitHub Pages에 그대로 올려서 홈페이지처럼 공개할 수 있고, 휴대폰 홈 화면에 설치하면 앱처럼 사용할 수 있습니다.


- 서비스 지역: 중산지구·시지 집중관리 · 대구·경산 전지역
- 브랜드: **집앞세차-앳홈 카케어 | At Home Car Care**

## 주요 기능

- 차종별 요금표 (일일세차·월세차·추가 옵션) — 요금은 `prices.js` 한 곳에서 관리
- 비회원 방문세차 예약 (2단계 입력, 예상 금액 자동 계산, 개인정보 동의)
- 월세차 라운지 (절약 계산기, 혜택 안내)과 월회원 신규 신청
- 내 예약: 비회원 예약 조회(휴대폰+차량번호), 월회원 카카오 로그인·일정 확인
- 쿠폰(리뷰·소개·월세차)과 혜택 자동 판별
- 세차 전·후 사진 갤러리, 고객 후기, 네이버 블로그 작업 일지 자동 연동
- 카카오톡 채널·문자 문의
- 관리자 화면(`#/admin`): 예약 관리, 일정 달력, 월세차 계약, 번호 연결 승인, 쿠폰·후기·사진 관리, 새 예약 푸시 알림
- 개인정보처리방침(`privacy.html`), 요금 페이지(`price.html`)
- PWA 설치 및 오프라인 캐시

## 파일 구성

앱 화면(`index.html`)이 불러오는 파일은 아래 6개입니다. 순서가 곧 적용 순서입니다.

| 파일 | 하는 일 |
| --- | --- |
| `core.css` | 기본 화면·홈·월세차 라운지·서비스 소개 스타일 |
| `features.css` | 회원·월세차 계약·예약 방식·개인정보 동의·요금 탭 스타일 (core.css 다음) |
| `prices.js` | 요금 데이터 — 요금은 여기서만 고칩니다 |
| `app.js` | 화면 이동, 예약 폼, 예상 금액, 갤러리·후기 |
| `supabase-integration.js` | 예약 저장, 관리자 화면, 쿠폰, 알림 (DB 연동) |
| `features.js` | 예약 단계 안내, 비회원 예약 조회, 월회원 화면, 관리자 계약·달력·번호 연결 (나중에 실행) |

`features.js`와 `app.js` 앞부분은 원래 따로 있던 파일을 같은 순서로 합친 것이라, 각 부분이 `/* ===== 원래파일명 ===== */`으로 표시되어 있고 한 부분에서 오류가 나도 나머지는 계속 동작하도록 감싸 두었습니다.
DB SQL은 `database/` 폴더에 실행 순서 번호를 붙여 모아 두었습니다. 순서와 설명은 `database/README.md`를 보세요.
GitHub Actions는 `blog-sync`(블로그 작업 일지)와 `sync-prices`(요금·오프라인 목록 동기화) 두 개만 사용합니다.
`index.html`에서 파일 버전(`?v=`)을 올리면 `service-worker.js`의 미리 저장 목록과 캐시 번호는 Actions가 자동으로 맞춥니다. 직접 확인: `node scripts/sync-sw.js --check`

## 요금 바꾸는 법

요금은 **`prices.js` 한 파일**에서만 고칩니다. 숫자를 바꿔 main에 올리면 끝입니다.

- 예약 화면 예상 금액, 옵션 칩, 월세차 절약 계산, 요금 탭 목록·옵션·관리 안내, 요금 페이지(`price.html`)가 모두 그 값을 읽어 그립니다.
- GitHub Actions **요금 동기화**가 HTML의 기본 글자(검색엔진용)와 "외부세차 ○○원부터" 문구도 자동으로 맞춥니다.
- 직접 확인: `node scripts/sync-prices.js --check` → "요금 일치"가 나오면 정상입니다.
- 예외: 차종별 전체 요금표 **이미지**(`assets/info/price-table.jpg`)는 새로 만들어 올리고, `index.html`의 `price-table.jpg?v=` 숫자를 바꿔야 합니다.
- 첫 달 할인·같은 아파트 할인 같은 **혜택 금액**은 요금이 아니라 `app.js` 맨 위 `DEFAULT_PROMOS`에 있습니다.

## GitHub Pages 배포

저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택하고 `main / root`를 지정하면 됩니다.

배포 후 Android Chrome에서는 **앱 설치 / 홈 화면에 추가**, iPhone Safari에서는 **공유 → 홈 화면에 추가**를 사용하면 앱처럼 실행할 수 있습니다.
