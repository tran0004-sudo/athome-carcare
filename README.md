# 집앞세차-앳홈 카케어 PWA

경산 **중산지구 · 사월동 · 시지 · 신매동**을 집중 대상으로 하는 아파트 방문세차용 모바일 PWA입니다. GitHub Pages에 그대로 올려서 홈페이지처럼 공개할 수 있고, 휴대폰 홈 화면에 설치하면 앱처럼 사용할 수 있습니다.

- 대표 연락처: **010-8391-8999**
- 서비스 지역: 경산 중산지구 · 사월동 · 시지 · 신매동 · 대구 전지역
- 브랜드: **집앞세차-앳홈 카케어 | At Home Car Care**

## 주요 기능

- 월세차 / 일일세차 요금표
- 차량 세차 예약 폼
- 세차 전·후 사진 갤러리
- 고객 사용후기
- 세차 카테고리와 관리 팁
- 전화 문의 버튼(010-8391-8999)
- 카카오채널 링크 설정
- 관리자 화면에서 사진·후기·팁 추가
- 공개용 `content.json` 내보내기
- PWA 설치 및 오프라인 캐시

## GitHub Pages 배포

저장소의 **Settings → Pages**에서 `Deploy from a branch`를 선택하고 `main / root`를 지정하면 됩니다.

배포 후 Android Chrome에서는 **앱 설치 / 홈 화면에 추가**, iPhone Safari에서는 **공유 → 홈 화면에 추가**를 사용하면 앱처럼 실행할 수 있습니다.

현재 전화번호는 **010-8391-8999**로 설정되어 있습니다.
